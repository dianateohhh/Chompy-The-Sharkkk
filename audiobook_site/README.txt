CHOMPY THE SHARK — AUDIOBOOK WEBSITE

This folder is ready to upload to a static web host.

FILES:
- index.html — audiobook page
- style.css — design
- script.js — player controls
- audio/chapter-01.mp3 — your narration
- images/cover.jpg — supplied cover

IMPORTANT:
The QR code cannot point to this folder until the website has a public URL. After hosting, use the public URL to create the final QR code.

A simple option is GitHub Pages or Netlify. Upload the contents of this folder (not the parent folder) to the host. The resulting public URL can then be turned into a QR code.
